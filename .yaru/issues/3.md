`package.json` の script 経由だと `bun yaru issue save ...` では足りず、実際は `bun yaru -- issue save ...` が必要。ヘルプは `yaru issue save` と書いてあるので、初めて叩くとフラグがコマンドに食われる。

直すならヘルプに bun 経由の例を書くか、bin をそのまま叩ける手順を先に出す。
