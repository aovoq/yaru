## 背景

Go 移行のあと、置き場所の重複や名前のかぶりが残っている。TS 版の削除は #15 で別に行う。

## やること

1. `spec/` (golden と画面のシナリオ) を `testdata/` にする (`testdata/golden`・`testdata/ui`)。`docs/spec/` (仕様書) と名前がかぶるため
2. `web/src` の `app/`・`pages/`・`board/` を整理する。板の部品は `board/` に寄せて `app/` を消す。proto からの変換 (`board/proto.ts`・`issue/proto.ts`・`domain/from-proto.ts`) は `domain/from-proto.ts` の 1 か所にする
3. フォントとアイコンの置き場所を 1 つにする。ルートの `assets/` (Go が同梱) と `web/public/fonts` の 2 か所にあるので、`web/public` にまとめ、Go は `web/dist` の同梱だけで配る
4. `internal/api` のファイル名を `<サービス>_service.go` にそろえる (`question.go`・`dashboard.go` など)。`internal/questions` は別パッケージのまま
5. `docs/migration/` は完了の記録として残し、AGENTS.md の構成の節を新しい置き場所に合わせる

## 確かめること

- `nix develop --command make go-check`、`cd web && npm run build && npm test`、golden の照合 (714 場面) が通る
- `make install` で反映して、板・issue・Dashboard・端末が開ける
