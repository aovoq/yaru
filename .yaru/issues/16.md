## 背景

Go 移行のあと、置き場所の重複や名前のかぶりが残っている。#15 (TS 版の削除) と合わせて、次の順で片付ける。消す前に Go だけで golden を照合できるようにし、#15 を「消すだけ」にする。

## やること

1. golden の照合を Go で動かす
   - `spec/` を `testdata/` にする (`testdata/golden`・`testdata/ui`)。`docs/spec/` (仕様書) と名前がかぶるため
   - Bun のランナー (`spec/golden/run.ts`) を Go のテストに移す。記録 (snapshots) はバイト単位で同じに書けること
   - `capture.sh`・`make-fixture.sh` を Bun なしで、worktree から作った Go の実行ファイルで動かす
2. #15 を行う (`ts-final` のタグを付けてから TS 版を消す)
3. フォントとアイコンの置き場所を 1 つにする。ルートの `assets/` (Go が同梱) と `web/public/fonts` の 2 か所にあるので、`web/public` にまとめ、Go は `web/dist` の同梱だけで配る。アイコンを作る道具 (`src/icons.ts`) も web 側へ移す
4. `web/src` を整理する
   - `app/` を `board/` に入れて消す
   - proto から画面用の形に直す関数 (`issueFromProto` など) を `domain/from-proto.ts` の 1 か所にする。要求の組み立てとエラーの変換は各画面の `proto.ts` に残す
   - `pages/board-page.tsx` のコメントの古い参照を直す
5. `internal/api` のサービスのファイル名を `<サービス>_service.go` にそろえる (`question.go`・`dashboard.go`・`inbox.go`)。サービスでないファイルはそのまま。`internal/questions` は別パッケージのまま
6. AGENTS.md・README の構成の節を Go 版の置き場所に合わせる。`docs/migration/` は完了の記録として残す

## 確かめること

- `nix develop --command make go-check`、`cd web && npm run build && npm test`、golden の照合 (714 場面) が通る
- `make install` で反映して、板・issue・Dashboard・端末が開ける
