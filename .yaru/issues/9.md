Linear MCP を参考にするなら issue に足すのはこの2つ。ラベルは今の文字列配列のままで、カタログ化しない。

キーは dueDate / priority。assignee と同じく frontmatter に常に書く。なしは空。古いファイルにキーがなくてもなし。save で省略したら触らない。空か none で外す。

dueDate は YYYY-MM-DD の暦日。時刻も SLA もない。ローカルの今日より前だけ overdue。当日限りは overdue でない。

priority は閉じた列挙 urgent | high | medium | low。なしがデフォルト。Linear の 0–4 は使わない。ラベルで p0 / urgent を表さない。

不正値（存在しない日付、未知の priority）は save が拒否。壊れた手編集は今どおり list がスキップ。

並びは updatedAt 降順のまま。最初のフィルタは --due overdue だけ。日付指定や --order は後回し。

CLI は既存の save / list / get に載せる。create / update は分けない。

スライス:

1. dueDate を store + CLI（persist、省略/クリア、不正拒否、list/get/save、--due overdue）
2. dueDate をボード（カード、リスト行、ドロワー、overdue が分かること）
3. priority を同じ順で（store + CLI、それからボード）
