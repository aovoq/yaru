## 背景

yaru は Go (API・データ・CLI・端末) と Vite + Preact の SPA に移し、2026-09-28 に常駐と CLI を `~/.local/bin/yaru` (make install) に切り替えた。問題が起きていないので、#16 の手順 2 として同じ日に消す。golden の照合は先に #16 の手順 1 で Go に移しておく。

## やること

- 消す直前のコミットに `ts-final` のタグを付ける
- `src/` (TS 版の CLI・サーバー・画面)、`dist/`、`bun.lock`・`bunfig.toml`・`tsconfig*.json`、ルートの `package.json` の TS 版だけが使うもの (依存・scripts)
  - 整形 (oxfmt) はルートに残し、`npm run fmt` で動かす
- flake から bun を外す
- `YARU_BIN` の既定を Go の実行ファイルにする (#16 の手順 1 で済ませる)
- AGENTS.md・README の TS 版の記述 (構成の節、hono・preact-render-to-string・`renderDocument` など)
- `docs/migration/PLAN.md` の台帳に完了を書く

## 残すもの

- Go のコメントや `docs/spec/` にある `src/index.ts:123` のような参照は、`ts-final` のタグの時点のファイルを指すものとして残す。書き換えると数百か所になり、移行の根拠を追えなくなるため

## 確かめること

- `nix develop --command make go-check`、`cd web && npm run build && npm test`、golden の照合が通る
- `make install` で反映して、板・issue・Dashboard・端末が開ける

## 戻し方

`git checkout ts-final -- src package.json bun.lock tsconfig.json tsconfig.client.json bunfig.toml` で TS 版を取り出し、`bun run build` で `dist/yaru.js` を作る。常駐は `~/dotfiles/home/modules/yaru.nix` の実行ファイルを `dist/yaru.js` (bun) に戻して `make switch`、CLI は `bun link`。
