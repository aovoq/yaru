## 背景

yaru は Go (API・データ・CLI・端末) と Vite + Preact の SPA に移し、2026-09-28 に常駐と CLI を `~/.local/bin/yaru` (make install) に切り替えた。TS 版は戻し先として残している。

## やること

数日使って問題が無ければ、次を消す。

- `src/` (TS 版の CLI・サーバー・画面) と、`package.json`・`bun.lock`・`tsconfig*.json`・`bunfig.toml` のうち TS 版だけが使うもの
- `dist/yaru.js` と `bun run build` まわり
- `spec/golden` のランナーは Bun で動くので、Go だけで照合できる形に移すか残すかを決める (golden の記録そのものは残す)
- `YARU_BIN` の既定 (今は `bun src/index.ts`) を Go の実行ファイルに替える
- AGENTS.md・README の TS 版の記述 (構成の節、hono・preact-render-to-string・`renderDocument` など)
- `docs/migration/PLAN.md` の台帳に完了を書く

## 確かめること

- `nix develop --command make go-check`、`cd web && npm run build && npm test`、golden の照合が通る
- `make install` で反映して、板・issue・Dashboard・端末が開ける

## 戻し方 (消す前まで)

TS 版に戻すには、`~/dotfiles/home/modules/yaru.nix` の実行ファイルを `dist/yaru.js` (bun) に戻して `make switch`、CLI は `bun link`。
